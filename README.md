# BMI Calculator 🧮

This is a beginner-friendly **BMI (Body Mass Index) Calculator** built with **Python**.

I created this project as my **first Python project** while learning programming.  
The goal was to practice basic concepts and also try building a simple **GUI application**.

## 🔰 Beginner Project

This project is made for learning purposes and is suitable for Python beginners.

## 🖥️ Interface

- The application uses **Tkinter** for a simple graphical user interface (GUI)
- User interaction is done through input fields and buttons (not the terminal)

## 📥 How It Works

- The user enters their **weight (kg)**
- The user enters their **height (meters)**
- The program calculates the BMI
- The result is displayed on the screen
- Invalid inputs are handled using `try / except`
